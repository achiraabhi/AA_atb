Static visual mockup — Transformer Editor. This is a non-interactive reference for how the editor should look. Two screens are shown: ① Topology mode (build the transformer, a winding selected) and ② Validate mode (make segment-pair rules, a rule selected). Layout is fixed: toolbar on top, 220 px meta panel left, flexible canvas center, 248 px inspector right. Only the coil diagram is script-drawn; there is no app logic. Colors, fonts, spacing, and structure are the target.
